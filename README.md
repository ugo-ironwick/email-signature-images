# email-signature-images

Images pour la signature courriel, servies via jsDelivr.

## Utilisation

1. Dépose tes images dans le dossier `images/`.
2. Lance `./publish.sh` (ou fais-le manuellement : `git add`, `git commit`, `git push`).
3. L'URL publique de chaque image est :

   https://cdn.jsdelivr.net/gh/ugo-ironwick/email-signature-images/images/NOM_DU_FICHIER

   Exemple : `images/logo.png` → https://cdn.jsdelivr.net/gh/ugo-ironwick/email-signature-images/images/logo.png

Note : jsDelivr met les fichiers en cache (~7 jours). Si tu remplaces une image en gardant le même nom, le changement peut prendre un peu de temps à apparaître. Pour un changement instantané, renomme le fichier (ex: logo-v2.png).
